# Java → AI Agent · 最近 4 周冲刺清单（每周约 10 小时）

> 压缩自《Java转AI-Agent四个月学习计划》前 12 周精华  
> 节奏：**工作日 1.5h × 5 + 周六 2h + 周日 0.5h 复盘 ≈ 10h/周**  
> 前提：有 Java/Spring 基础；已用过 Dify（可加速理解，但仍要用 Java 复刻）  
> 模型：DeepSeek 或通义；框架优先 **Spring AI**，Agent 加深可看 LangChain4j  
> 仓库建议：`java-ai-agent-learning`

---

## 四周目标一览

| 周 | 主题 | 本周交付（必须可演示） | 约 10h 用在哪 |
|----|------|------------------------|---------------|
| W1 | 会调模型 | Spring Boot **流式聊天** API | Prompt + API + Spring AI |
| W2 | RAG | **上传文档 → 问答带来源** | 向量库 + 检索问答 |
| W3 | Agent | **Tool Calling**（查单/建单类） | 工具循环 + 业务 Tool |
| W4 | 闭环作品 | 知识库 + Agent **整合 Demo** + README | 拼装、打磨、简历话术 |

**4 周后最低验收**

- [ ] 流式对话可用  
- [ ] RAG 能引用 chunk  
- [ ] Agent 至少 2 个 Tool 可被自然语言触发  
- [ ] GitHub 有 README + 可本地跑（或 Docker）  
- [ ] 能用 5 分钟讲清架构

## 第 1 周｜会调模型（流式聊天）

**本周唯一交付：** `POST /api/chat`（流式 SSE）+ 简单会话记忆 + README  

| 天 | 时长 | 必做（完成才算过） | 不做 |
|----|------|-------------------|------|
| 一 | 1.5h | Token/上下文/温度/幻觉 笔记半页；开通 API；`curl` 调通一次聊天 | 不看长课 |
| 二 | 1.5h | 写 5 条有效 Prompt（角色/任务/约束/JSON 输出）；Java `HttpClient` 打印回复 | — |
| 三 | 1.5h | 新建 Spring Boot 3 + Spring AI；配置 Key；非流式 `ChatClient` 跑通 | 不纠结多模型 |
| 四 | 1.5h | SSE 流式接口；Postman/curl 可见逐字输出 | — |
| 五 | 1.5h | Prompt Template（系统提示 + 变量）；按 `sessionId` 内存保留最近 N 轮 | 不上 DB |
| 六 | 2h | 结构化 JSON 输出 + 失败重试 1 次；补 README；Git 推送 | 不做前端 |
| 日 | 0.5h | 复盘；确认「能独立讲清如何调 LLM」 | — |

**周日检查清单**

- [ ] curl / Postman 流式 OK  
- [ ] 多轮同一 `sessionId` 能接上上下文  
- [ ] 密钥未进 Git  

**入口：** Spring AI Getting Started / ChatClient / Streaming；DeepSeek 或百炼文档

## 第 2 周｜RAG 全链路（就业核心）

**本周唯一交付：** 上传 PDF/MD → 入库 → 提问 → **答案带 chunk 来源**；无资料时拒答  

| 天 | 时长 | 必做 | 不做 |
|----|------|------|------|
| 一 | 1.5h | Embedding/切分/TopK 笔记；Docker 起 Postgres+pgvector（或已有库） | 不折腾 Milvus |
| 二 | 1.5h | DocumentReader 解析文档；chunk + overlap；写入 VectorStore | — |
| 三 | 1.5h | 按问题检索 TopK；打印相似度/内容；调 chunk 大小试 2 组 | — |
| 四 | 1.5h | Spring AI RAG/Advisor：问答接口；返回答案 + 来源列表 | 不做 Hybrid |
| 五 | 1.5h | 拒答策略（低分/无命中）；记录 10 条人工评测题结果 | 不上队列 |
| 六 | 2h | 上传 API + 问答 API 联调；与 Dify 同文档对比半页笔记；README | 不追求高并发 |
| 日 | 0.5h | 复盘：幻觉如何降低（检索+拒答+引用） | — |

**周日检查清单**

- [ ] 至少 1 份文档可问可引用  
- [ ] 故意问库外问题会拒答或明确说不知道  
- [ ] 有「切分/TopK」调参记录 5 行以上  

**入口：** Spring AI VectorStore / RAG；pgvector 文档；你已有的 Dify 知识库经验作对照

## 第 3 周｜Tool Calling Agent

**本周唯一交付：** Agent 可自然语言触发 **≥2 个 Tool**（例：查订单状态、创建工单/记录）；能看到调了哪个工具  

| 天 | 时长 | 必做 | 不做 |
|----|------|------|------|
| 一 | 1.5h | 搞清循环：思考→调工具→观察→回答；画 1 张时序图；`@Tool` 玩具工具（计算器） | 不多 Agent |
| 二 | 1.5h | Tool1：只读查订单（可用内存 Map/H2 模拟） | 不上复杂权限 |
| 三 | 1.5h | Tool2：创建工单/待办（写库或内存）；回复不泄密字段 | — |
| 四 | 1.5h | 同一 Agent：**RAG 检索 + 业务 Tool** 并存；Prompt 写清何时用库/何时调工具 | — |
| 五 | 1.5h | 超时/工具失败友好提示；日志打印 tool name + 耗时 | 不做二次确认全套 |
| 六 | 2h | 端到端脚本：问政策→查单→建单；录 1～2 分钟屏；对照 Dify Agent 差异 5 行 | — |
| 日 | 0.5h | 复盘：Agent vs 纯 RAG 一句话区别 | — |

**周日检查清单**

- [ ] 至少 3 个成功用例（纯问答 / 调 Tool1 / 调 Tool2）  
- [ ] 日志或返回里能看见工具名  
- [ ] 工具异常时用户能看懂  

**入口：** Spring AI Tools / Function Calling；可选 LangChain4j AiServices 扫一眼

1. 建仓库 `java-ai-agent-learning`，加 `.gitignore`（排除 `.env`）

```bash
curl https://api.deepseek.com/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $API_KEY" \
  -d '{"model":"deepseek-chat","messages":[{"role":"user","content":"用三句话介绍 RAG"}]}'
```
