# Java 转 AI Agent 应用工程师 · 四个月学习计划

> 适用人群：有 Java / Spring 基础、约 30 岁、目标转向 **AI Agent / 大模型应用工程**（非纯算法）  
> 城市参考：长沙（本地落地 + 远程均可）  
> 每天投入：工作日约 **1.5–2 小时**，周末约 **4–5 小时**  
> 技术主线：**Java 17+ · Spring Boot 3 · Spring AI（主）· LangChain4j（Agent 加深）· PgVector/Milvus · Redis**  
> 模型建议：**DeepSeek / 通义千问（阿里云百炼）**（国内易用、成本可控）

---

## 1. 目标定位

### 1.1 就业方向（优先）

| 优先级 | 方向 | 说明 |
|--------|------|------|
| ★★★ | Agent 应用工程师 | Tool Calling、编排、RAG + 业务系统对接 |
| ★★★ | AI 后端 / LLM 工程化 | 网关、限流、评测、向量库、可观测、成本控制 |
| ★★ | 垂直行业 Agent | 政务 / 医疗 / 制造 / 客服等落地（长沙更友好） |
| ★ | 纯算法 / 预训练 | 不推荐作为主路线（门槛与年龄性价比低） |

### 1.2 四个月后你应具备

- 独立用 Spring Boot 搭建流式对话服务  
- 完成文档入库 → 检索 → 带出处回答的 RAG 系统  
- 实现可调业务接口的 Tool Calling Agent  
- 具备基础生产能力：日志、限流、降级、评测、成本统计  
- 有一个可演示、可写进简历的完整作品仓库  

### 1.3 最终作品（简历项目）

**企业内部知识库 + 工单/业务 Agent**

建议能力清单：

1. 文档上传与向量化入库  
2. 知识库问答（答案带来源片段）  
3. 工具调用：查订单 / 建工单 / 查知识库  
4. 流式输出 + 会话记忆  
5. 操作审计、限流、token 成本统计  
6. Docker Compose 一键启动 + README 架构图 + 演示录屏

## 10. 简历项目描述模板（可直接改）

**项目名称：** 企业知识库问答与工单 Agent 系统  

**角色：** 独立开发（Java / Spring AI）  

**项目描述：**  
基于 Spring Boot + Spring AI 构建企业内部智能助手，支持文档知识库问答与业务工具调用。完成文档解析与向量化检索（RAG）、流式对话、订单查询与工单创建等 Agent 能力，并补充链路日志、限流降级与 token 成本统计，达到可演示的工程化水准。  

**技术栈：** Java 17、Spring Boot 3、Spring AI、LangChain4j、PostgreSQL、pgvector、Redis、Docker  

**业绩要点（按实际填写）：**

- 搭建完整 RAG 链路，问答支持来源引用；评测集 N 条，关键问题命中率 X%  
- 实现 Tool Calling Agent，覆盖查单 / 建单等业务动作，平均响应耗时 XXs  
- 增加 trace 日志与费用统计，支持按日观察 token 成本
